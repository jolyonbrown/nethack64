# 2026-11-20 — Codex review of ADR-0010 (T2.12)

**Changed**

Reviewed the proposed character-pointer ABI against the fork, libc, generated bank glue, HAL and archived whole-game maps. Recommend revising the ADR before implementation.

**Verified**

`make all prg test memmap` passed, including all five baseline VICE configurations. Booted the baseline EasyFlash cartridge with 512 KB REU on monitor port 6503, sent `l`, observed movement in the screen shadow and quit. The proposed compiler feature has no executable here.

**Measured**

Summed the lengths of the resident anonymous `DATA:code` objects in the archived error maps using the object pattern in `tools/measure/trace/layout.py`. Far26 has 17,044 bytes and far27 has 11,896. The far27 map has 26,015 bytes of named resident native code in the code section. The proposed address range holds 16,384 bytes. Far28 classified 15,790 bytes of mixed objects and stopped before linking.
