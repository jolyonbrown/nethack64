The timing loop reads both through a byte pointer, so the near copy pays the character test
(a call of farxl6 that finds the page below $C1) and the far one the table look-up: about
11.6 cycles a byte more for a far byte in the cache. The compiler uses farxl6/farxo6 (the page
form): with farxz6, a pointer stepped in a loop loses its carry (ADR-0010, "Built").
