So the resident side is the same size as the C64's (about 58.3 KB: the same code, a few
bytes apart), and the C128 offers 36.6 KB of regions for it as laid out here, against the
C64's real budget of about 25 KB (RAM-PLAN.md).  Not counted yet: the RAM under the I/O
(4 KB, if the program ran with the I/O out, $3F/$3B, and switched it in around the chips, as
Oscar64's C128 start does), $0400-$1BFF (6 KB, if the KERNAL's workspace is given back
around KERNAL calls), and what the page cache, stack and near heap take.
